# Contributing to Checkmate

Thanks for your interest in contributing. The contributor guide lives in the Checkmate documentation:

**[checkmate.so/docs/getting-started/contributing](https://checkmate.so/docs/getting-started/contributing)**

It covers local setup, reporting bugs, suggesting features, translations, the pull request checklist and the branching model.

The short version:

- Pick an issue (start with [`good first issue`](https://github.com/bluewave-labs/checkmate/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)) and ask to be assigned.
- Branch from `develop` and open your pull request against `develop`.
- Run `npm run lint`, `npm run format-check` and `npm run build` in both `client` and `server` before you open it.

Questions are welcome on [Discord](https://discord.com/invite/NAb6H3UTjK) and in [GitHub Discussions](https://github.com/bluewave-labs/checkmate/discussions).
